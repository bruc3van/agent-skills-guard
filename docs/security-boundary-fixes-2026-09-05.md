# 安全边界修复记录（2026-09-05）

基线：v1.3.6 / 691bce3。本次按核实后的四组范围修复，没有升级应用版本。

## 路径卸载与插件安装

- 按路径卸载先检查目标是否属于当前技能登记的安装目录项，再删除。允许合法自定义安装位置；登记链接不授权删除链接目标。拒绝根路径、父级跳转、未登记的文件/目录。
- 插件安装先 prepare、显示报告、确认。后端拒绝未准备、已阻断和扫描不完整的插件，确认时重新扫描缓存，并在执行安装前扫描 Claude 实际使用的本地插件来源。
- 插件名、marketplace 名称和来源路径均校验；拒绝重复同名入口、越界来源。安装参数由后端构造，不再执行元数据中的自由命令参数。
- 阻断后保留报告并停止安装；界面提供重新扫描入口。
- 独立远程 source 目前无法验证最终安装内容，因此明确拒绝自动安装。该限制会影响部分市场插件，不能把扫描 marketplace 的结果视为扫描了这些远程插件。

## 命令规则与 Windows

- 补齐根目录/根通配符位于不同参数位置、长选项、绝对路径 shell、env/sudo/busybox 包装及 base64 管道执行检测，保留安全路径和仅下载等负例。
- Windows Junction 改用 `junction` 原生 API，失败仍可降级复制，不再执行 `cmd /C mklink`。
- 必须调用 `.cmd/.bat` 的 PTY、扫描及更新检查路径统一拒绝 shell 控制/展开字符，并使用 `/d` 禁止 AutoRun。含这些字符的 CLI 启动路径/参数会被明确拒绝。
- 包名按 npm/pnpm、pip、Homebrew、Scoop、Chocolatey 分别校验，保留 scoped package、tap、bucket 等合法标识，拒绝 URL、Git 来源、路径跳转和选项注入。

## 后续审查复核

- 根目录别名漏报已复现并补齐：`/.`、`//`、`/./`、`/..`、`/../`、组合形式、引号及根通配符。回归测试修复前在 `rm -rf /.` 失败，修复后通过；同时验证 `/./tmp/build`、`/../tmp/build`、`//tmp/build`、`/.cache` 等不被当作根目录。这里检测危险意图，不宣称这些样本在所有 rm 实现上都能删除根目录；GNU rm 默认保护解析到根目录的路径，参见 [GNU 文档](https://www.gnu.org/software/coreutils/manual/html_node/Treating-_002f-specially.html)。
- Unicode 三个样本确实不报警，但尚未证明可执行绕过。隔离 Bash 夹具中，`rm\u{200B}` 和全角 `ｒｍ` 均找不到命令；`/\u{200B}` 作为参数保留零宽字符，不是 `/`。夹具将 ASCII rm 替换为只打印参数的函数，没有执行文件删除。未对原始脚本直接做 NFKC/零宽剥离；混淆文本检测属于后续加固，若存在下游归一化再执行的链路，应单独评估。
- README 跳过是现存覆盖限制；非法 ZIP 条目跳过是现存完整性策略限制，但不是已证明的越界写入。两者此次未扩展处理。
- 自定义新安装位置属于已有功能，不能仅凭可指定位置判为任意写漏洞；若要求限制失陷 renderer，需要另行设计后端安装位置授权。
- 仓库链接协议限制可加固，但当前审查未证明远程导航到本地 IPC 的完整利用链。
- `localCli.managers.native/unknown` 缺失属实，是独立的界面翻译缺陷，尚未修复。

此次补充后重新执行完整 Rust 测试：558 个通过；rustfmt 与 diff 空白检查通过。此次仅补充规则、已有回归测试与本文档，没有再次修改前端。


## 本地评分误报修正

实际报告复核发现，跨技能持久化使原有宽泛启发式的扣分持续生效：普通文档中的 token 等词和其他技能的网络文本触发 High，公共文档/模式域名触发 Medium。它们只能证明文本共现，不能证明数据中继或协同攻击。

- 四类现有跨技能启发式保留为 Info / Low confidence 关联提示，显式权重为 0；说明文字不再声称已发现外传或协同攻击。
- 分析器到报告的转换保留显式零权重，数据库重读、单技能重扫、跨技能刷新均不恢复扣分。仅调整这些弱关联线索；原危险命令等检测和安装闸门保留。
- 用本机 6 个技能的只读数据与临时数据库隔离复算，并重新扫描实际文件：xlsx、pptx、frontend-design、docx 为 100；skill-creator 为 97（保留自身低风险项）；dsh-plugin-upgrade 为 100。正式数据库未由诊断脚本修改，使用新应用重扫后刷新报告。
- Rust 全量 559 个测试通过；新增覆盖全部四类关联提示零扣分、实际危险命令仍阻断及零权重持久化。此记录中的分数是当前文件的扫描结果，不是固定白名单或安全保证。
